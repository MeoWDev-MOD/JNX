# JNX 23.5.0-0

🌐 **[Ler em português](README.md)**

Free homebrew pack for the Nintendo Switch (firmware 23.5.0), in Brazilian Portuguese.
If you paid for it, you were scammed.

## Download

Download `JNX-23.5.0-0.zip` from the [**Releases**](../../releases/latest) tab and extract **all of its contents to the root of the SD card**.

## Installation

1. Turn the console off and remove the SD card (FAT32 or exFAT).
2. Copy all the contents to the root of the SD card, replacing files if asked.
3. Launch `payload.bin` (through a modchip or RCM mode).
4. In the Hekate menu choose:
   - **Desbloqueado** (Unlocked): uses a copy of the system on the SD card (recommended; protects the original system).
   - **Semi-Desbloqueado** (Semi-unlocked): uses the original system with the homebrews.
   - **Sistema Original** (Original system): boots the Switch as it came from the factory.
5. To create the emuMMC: Hekate > emuMMC options > Create emuMMC. Back up the NAND first.
6. The pack's menus are in Portuguese; the homebrews follow the console's system language.

## What is in the pack

Atmosphère 1.12.2, Hekate 6.5.5 + Nyx (pt-BR), JNX Updater 3.0, Sphaira, AIO Switch Updater, Goldleaf, Checkpoint, JKSV,
